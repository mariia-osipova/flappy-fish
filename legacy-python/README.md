# Legacy Python Flappy Fish

This folder contains the old Python/Pygame version copied from commit `20c7e24`
(`readme changes, deploy`), the last Python-only version before the web app was added.

Run it from this folder:

```sh
cd legacy-python
python3 -m pip install -r requirements.txt
python3 main.py
```

Or run it from the project root:

```sh
python3 legacy-python/run.py
```

The code uses the existing project assets in `../data`.
